🎯 OBJETIVO GERAL
Construir uma plataforma escolar digital responsiva com login por tipo de usuário, dashboard inteligente, tema escuro/claro, relatórios avançados, e gestão de alunos, professores, notas, presença, eventos e boletins.

👤 USUÁRIOS E PERMISSÕES
Crie um sistema de autenticação com controle de acesso por perfis. Ao logar, cada usuário vê somente o que lhe é permitido.
